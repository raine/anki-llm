Create a prompt template by querying your Anki collection

Usage: anki-llm generate-init [OPTIONS] [OUTPUT]

Arguments:
  [OUTPUT]  Output file path

Options:
  -m, --model <MODEL>
          Model name
      --api-base-url <API_BASE_URL>
          Custom API base URL (e.g. https://openrouter.ai/api/v1, http://localhost:11434/v1)
      --api-key <API_KEY>
          API key (overrides environment variables)
      --reasoning-effort <REASONING_EFFORT>
          Reasoning effort passed to the model provider
  -t, --temperature <TEMPERATURE>
          LLM temperature (0-2)
      --copy
          Copy prompt to clipboard for manual LLM mode
  -h, --help
          Print help
